Van Arkel–Ketelaar triangle for IB Chemistry

Enter two element symbols, then select Plot.

How does this work?

Δχ = |χa − χb|

χavg = (χa + χb) / 2

Difference determines the vertical position. Average determines the horizontal position.

The triangle represents a continuum of bonding character rather than strict bond-type boundaries.
